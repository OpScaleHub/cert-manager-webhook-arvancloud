Quick start

Install in two commands

Add the OpScaleHub Helm repository and deploy the webhook into your cert-manager namespace.

shell — add repo & install 
# 1. Add the OpScaleHub chart repository
helm repo add opscalehub https://opscalehub.github.io/cert-manager-webhook-arvancloud
helm repo update

# 2. Install the webhook alongside cert-manager (add --version to pin)
helm install arvancloud-webhook opscalehub/arvancloud-webhook \
  --namespace cert-manager

# 3. Provide your ArvanCloud Machine User API key
kubectl -n cert-manager create secret generic arvancloud-credentials \
  --from-literal=api-key=<YOUR_MACHINE_USER_KEY>

Configuration

Point a ClusterIssuer at the webhook

The groupName acme.arvancloud.ir routes DNS-01 challenges through the solver. That's the entire integration.

clusterissuer.yaml 
apiVersion: cert-manager.io/v1
kind: ClusterIssuer
metadata:
  name: letsencrypt-arvancloud
spec:
  acme:
    server: https://acme-v02.api.letsencrypt.org/directory
    email: platform@example.com
    privateKeySecretRef:
      name: letsencrypt-arvancloud-account
    solvers:
      - dns01:
          webhook:
            groupName: acme.arvancloud.ir
            solverName: arvancloud
            config:
              apiKeySecretRef:
                name: arvancloud-credentials
                key: api-key
              ttl: 120
              propagationCheck: true
  • Idempotent lifecycle. Present reuses an identical existing TXT record; CleanUp treats a missing record as success — no error loops.
  • Multi-level subdomains. Correctly resolves the zone apex for names like *.apps.cluster.example.com.
  • Propagation gate. Blocks by default until 1.1.1.1 and 8.8.8.8 both serve the challenge record; set propagationCheck: false to opt out.
  • Locked-down pod. Runs as non-root 10001, read-only root filesystem, all capabilities dropped, RuntimeDefault seccomp.
  • Prometheus metrics. API latency & error-rate histograms and challenge success/failure counters on :8081/metrics, with an optional ServiceMonitor.
  • Schema-validated chart. values.schema.json catches missing secret bindings and invalid replica counts at helm install time.
